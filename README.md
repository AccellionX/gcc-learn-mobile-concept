# GCC Learn — Mobile Concept by AccellionX

Pitch demo for Gravity Management Consulting: a polished native-app concept showing how their existing Lovable (React) e-learning platform would look and feel as iOS and Android apps.

## Stack

- React + Vite + TypeScript + Tailwind CSS
- Mock data / local state only (no backend)
- Arabic (default) + English with full RTL
- Desktop device frames (iPhone / Android) · full-screen on mobile

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to Vercel (SPA rewrites included via `vercel.json`).

## Concept pages

- `/` — interactive mobile app demo
- `/how` — technical walkthrough (“How we’d build it”)

Prepared by AccellionX for Gravity Management Consulting — not an official build.
